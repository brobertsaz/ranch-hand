# Ranch Hand

A mobile app for working ranches. Ride out, drop a pin, snap a photo — and whoever rides out next can find it. It works with no cell signal.

## The problem

Ranch work happens in places with no signal, and today most observations end up as "remember to tell someone" or a note on paper. Some examples:

- A sick cow seen a quarter mile out on Tuesday morning. Which cow? Where exactly?
- Feed stations in the middle of a pasture that someone restocks every couple of days
- Water tanks, gates, and a fence that needs fixing

## The core idea

**One-tap observations.** Take a photo with the ear tag in frame, and the app records GPS and time automatically. Pick a type (sick animal, feed, water, fence, gate, other) and add a note if you want. The observation is saved on the phone right away and syncs to the rest of the crew when you're back in range.

**A shared ranch map.** It shows the ranch's own private waypoints, not public trails. Everyone working the ranch sees the same pins.

**Ride tracking.** Record where you rode, so a path shows where an observation was made.

**No hardware.** Use the phone the hand already carries and the tag the cow already wears.
